# Small Job Tools

Eight free, browser-based tools for life's small jobs:

- [Wedding hashtag generator](https://smalljobtools.com/wedding-hashtags/)
- [Moving checklist](https://smalljobtools.com/moving-checklist/)
- [Dog name generator](https://smalljobtools.com/dog-names/)
- [Garden material calculators](https://smalljobtools.com/garden-calculators/)
- [Cat name generator](https://smalljobtools.com/cat-names/)
- [Car maintenance planner](https://smalljobtools.com/car-maintenance/)
- [Camping checklist builder](https://smalljobtools.com/camping-checklist/)
- [Home maintenance planner](https://smalljobtools.com/home-maintenance/)

No signup. Inputs stay in the browser. Static site served by GitHub Pages at [smalljobtools.com](https://smalljobtools.com/).
