Privacy, in plain English.

Cat Name Club is a browser tool, not a data business. Here is what happens to your shortlist.

Your shortlist stays in the tab

The name board runs as JavaScript in your browser. Saved names are stored in this browser's local storage. This page does not send them to a server.

No accounts, no uploads

There is no signup, no login, no file upload, and no email capture. The copy buttons use your browser's clipboard.

Hosting logs

Like any website, the static host that serves these pages may keep standard server logs (IP address, user agent, requested URL) for security and reliability.

Analytics

We use Google Analytics 4 (Measurement ID G-5QWJZ0635S) to count visits and learn which pages and tools are useful. Analytics is off until you choose Allow. If you allow it, the page sends a cookieless measurement request to Google and may keep a random analytics client ID in this browser’s local storage. We do not set analytics cookies. Google may process visit data as described in Google’s privacy policy. If you decline, no analytics request is sent.

Warrior names

The warrior generator is fan-made and is not affiliated with the Warriors book series. It uses no official art, logos, or character names.

Questions

Questions about this policy? Write to hello@catnameclub.com.
