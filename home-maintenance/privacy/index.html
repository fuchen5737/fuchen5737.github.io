Privacy, in plain English.

House Rhythm builds a maintenance calendar in your browser. No account, no home history on a server.

Your home profile stays in the browser

The home type, age, climate, heating, selected features, and checked tasks are saved in this browser’s local storage. They are not sent to a server by the planner. Clearing browser data or switching devices will clear the saved plan.

No accounts, no uploads

There is no signup, no login, no file upload, and no email capture. The copy and print buttons use your browser’s clipboard and print dialog.

Hosting logs

Like any website, the static host that serves these pages may keep standard server logs (IP address, user agent, requested URL) for security and reliability.

Analytics

We use Google Analytics 4 (Measurement ID G-QT91VKFN8L) to count visits and learn which pages and tools are useful. The Google tag runs in consent mode on every page. Before you choose, it does not send a pageview or set analytics cookies. If you allow it, Google may set cookies and process visit data as described in Google’s privacy policy. If you decline, analytics storage stays off.

General guidance

House Rhythm is a maintenance planning tool, not a home inspection, engineering report, or warranty statement. Follow local codes and use licensed trades for work that requires them.
