Privacy, in plain English.

Good Dog Name is a browser tool, not a data business. Here is what happens to your shortlist.

Your shortlist stays in the tab

The name board runs as JavaScript in your browser. Your saved names are stored in this browser's local storage. This page does not send them to a server.

No accounts, no uploads

There is no signup, no login, no file upload, and no email capture. The copy buttons use your browser's clipboard.

Hosting logs

Like any website, the static host that serves these pages may keep standard server logs (IP address, user agent, requested URL) for security and reliability.

Analytics

We use Google Analytics 4 (Measurement ID G-QT91VKFN8L) to count visits and learn which pages are useful. The Google tag runs in consent mode on every page. Before you choose, it does not send a pageview or set analytics cookies. If you allow it, Google may set cookies and process visit data as described in Google’s privacy policy. If you decline, analytics storage stays off.

Questions

Questions about this policy? Write to hello@gooddogname.com.
